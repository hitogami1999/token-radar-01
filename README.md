A token launch radar: it reads a sealed DefiLlama snapshot, ranks every pre-token protocol by what its launch would be worth under a model built from the snapshot's own figures, and hands in a dashboard with the board, a detail view for each protocol, and a concrete farm plan for every row.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../token-radar-01-kit/input/snapshot.json
```
